# Chronoscope

> **Хроноскоп** — жестовой видеоприбор. Управляйте временем, цветом и гравитацией
> прямо в кадре веб-камеры. Без касаний. Без кнопок. Только рука.

Три эффекта, сплетённые в один инструмент: ударная волна инверсии цвета,
хронозона застывшего времени и настоящая гравитационная линза. Всё считается
в реальном времени прямо в браузере.

---

## Жесты

| Жест | Эффект |
|:----:|--------|
| ✌️ **два пальца** | **Волна инверсии** — светящийся фронт с хроматической аберрацией и рябью расходится от руки и «закрашивает» кадр негативом. Обратная волна возвращает цвета. Удар сопровождается тряской экрана и низким бумом |
| 🤟 **три пальца** | **Хронозона** — круглое поле застывшего времени под ладонью: внутри кадр замирает и покрывается голографическими скан-линиями, а из застывшего изображения рождаются частицы, кружащие вихрем вокруг руки. Поле таскается за рукой; при закрытии — взрыв частиц |
| 🤏 **щипок** | **Чёрная дыра** — в точке щипка пространство искривляется: свет закручивается спиралью и затягивается к тёмному ядру с фотонным кольцом, вокруг разгорается аккреционный диск. Дыра следует за рукой. Отпускаете — материя выстреливает ударной волной |
| ✊ **кулак** | **Сброс** — всё возвращается к исходному кадру |
| 🖐 **левая ладонь** | **Пси-линза** — круг, циклически перекрашивающий кадр радугой |

Скелет руки подсвечивается переливающимся неоном, ладонь оставляет радужный
след, каждое событие озвучено синтезом. Интерфейс — в эстетике оптического
прибора: статус-панель с индикаторами камеры, руки и FPS.

## Как запустить

Ничего устанавливать не нужно.

```bash
python3 -m http.server 8741
```

Откройте `http://localhost:8741`, разрешите доступ к камере — и покажите руку.

> При первом запуске модель распознавания рук (~5 МБ) загружается с CDN,
> дальше браузер её кэширует. Нужен интернет один раз.

## Под капотом

- **MediaPipe Hands** — 21 ключевая точка руки, 2 руки одновременно,
  распознавание жестов по геометрии с гистерезисом и дебаунсом
- **Canvas 2D** — весь рендер: слои кадров, кольцевые клипы, композитные
  режимы, Retina (до 2× DPR)
- **Гравитационная линза** — 30 концентрических колец с радиальным растяжением
  и закруткой; чёрная дыра искривляет всё, что под ней
- **Сглаживание** — экспоненциальный фильтр скелета и ладони, движения без дрожания
- **Web Audio** — синтезированные звуки событий, без единого аудиофайла
